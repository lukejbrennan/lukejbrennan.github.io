# Stoic Library

*Public-domain translations of the core Stoic works.*

- [Meditations](/notes/meditations/) — Marcus Aurelius, tr. George Long (1862). 12 books.
- [Enchiridion](/notes/enchiridion/) — Epictetus, tr. Thomas Wentworth Higginson (1865). 50 chapters.
- [Moral Letters](/notes/moral-letters/) — Seneca, tr. Richard M. Gummere (1917–25). 124 letters.
